# 개인 결정 기록 (현지)

구현하면서 제가 새로 정한 것을 적습니다. 팀 설계 문서([DESIGN.md](../DESIGN.md))의 결정 기록에는 합의된 내용만 들어가므로, 여기 적힌 것 중 "팀 결정 필요"가 "예"인 줄만 팀 회의에 가져가 논의한 뒤 DESIGN.md에 옮깁니다.

- 단계 번호는 DESIGN.md 3번의 개발 단계와 같습니다.
- 결정을 바꿀 때는 그 줄을 고치고, 이유 칸에 "(변경: 이전에는 ...)"을 덧붙입니다.
- 팀 회의에서 논의가 끝난 줄은 "팀 결정 필요" 칸에 결과를 덧붙입니다. 예: "예 → DESIGN.md 반영"

| 단계 | 결정 | 이유 | 팀 결정 필요 |
| --- | --- | --- | --- |
| 0 | 서버 도구는 Flask | 코드가 짧고, 6단계의 400 응답을 직접 작성하기 쉬움 | 아니오 (목요일은 각자 구현. 7단계에서 기준 구현을 고르면 함께 정해짐) |
| 0 | 패키지는 프로젝트 폴더 안의 가상환경(`.venv`)에 설치하고 `requirements.txt`에 기록 | 시스템 파이썬을 건드리지 않고, 같은 환경을 다시 만들 수 있음 | 아니오 (개인 개발 환경) |
| 0 | 서버 포트는 8000 | macOS에서는 Flask 기본 포트 5000을 AirPlay 수신 기능이 사용해 충돌할 수 있음 | 예 (8단계의 데모 API가 미니 레디스 주소를 알아야 함. 금요일 전에 정하면 됨) |
